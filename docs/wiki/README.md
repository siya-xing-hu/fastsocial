## 如何沉淀新经验

1. 用户确认的长期偏好、重复出现的问题及其有效解决办法，更新到对应 Wiki 页。
2. 需要所有后续任务遵守的短规则，同时补入根目录 `AGENTS.md`，链接到详细说明。
3. 能机械检查的约定加入现有检查流程，例如 `pnpm lint:ui`；需要判断的内容纳入实际页面验证和代码审查。
4. 业务行为变化时改写原有描述，而不是不断追加互相冲突的说明。文档与实现同一轮更新。

`docs/superpowers/specs/` 和 `docs/superpowers/plans/` 保留历史设计过程，其中 Prompt 模板、多用户监听、独立互关页面等方案可能已经被替代。当前约定以本 Wiki 和实现为准。

文档不能独自保证执行；本项目通过 **根目录规则 + 分类 Wiki + 自动检查 + 实际验证** 共同维护约定。涉及请求确认、账号隔离和外部动作时，自动检查通过也不能代替调用链审查。
